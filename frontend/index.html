How it works

A scheduled Lambda function scans every enabled region, reads the bill from Cost Explorer, and writes this report to a private S3 bucket.

Read-only

The scanner only has Describe, List and Get permissions. It cannot stop, delete or change anything.

No public API

Scans run weekly or with aws lambda invoke. This page never talks to AWS: it shows sample data or a report file you open, and the file stays in your browser.

Priced for real

EC2 prices come from the AWS Price List API and spend comes from Cost Explorer. Other prices use published us-east-1 rates and are marked "estimate".
